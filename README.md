# Менеджмент в профессиональной деятельности (РПО)

Репозиторий с выполненными практическими, домашними и самостоятельными работами по дисциплине **«Менеджмент в профессиональной деятельности»** (направление «Разработка программного обеспечения»).

## Содержание репозитория

| № | Тема работы | Директория и конспект | Исходный формат | Краткое содержание |
| :-: | :--- | :--- | :--- | :--- |

| **02** | Типы организаций и управленческие кейсы | [`02-organization-types-and-cases`](./02-organization-types-and-cases/README.md) | DOCX | Формальные и неформальные, простые и сложные организации; кейс «CodeFast vs TechWorld» |
| **03** | Сравнительный анализ управленческих подходов | [`03-management-approaches-comparison`](./03-management-approaches-comparison/README.md) | DOCX | Сравнение моделей управления промышленной госкорпорации («Росатом») и цифровой платформы («Яндекс Маркет») |

| **06** | Карта рисков на проектную задачу | [`06-task-risk-map`](./06-task-risk-map/README.md) | PDF | Оценка вероятности и влияния рисков, превентивные меры и план B для Python-модуля распознавания жестов |
